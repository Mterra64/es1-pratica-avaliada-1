# Prática Avaliada 1 - Engenharia de Software I

Projeto desenvolvido para a disciplina de Engenharia de Software I da FGV.

A atividade utiliza o cenário da AgileTech Solutions para aplicar conceitos de desenvolvimento ágil estudados na disciplina, incluindo Manifesto Ágil, Scrum, Extreme Programming (XP), Kanban e Design Simples.

## Estrutura do projeto

- `analise-processo.md` - análise do processo de desenvolvimento, Manifesto Ágil, programação em pares e dificuldades essenciais de Brooks.
- `processo-xp-scrum.md` - proposta de processo combinando práticas de XP, Scrum e Kanban.
- `analise-yagni.md` - análise da aplicação do princípio YAGNI.
- `src/usuario_simples.py` - implementação simplificada do gerenciamento de usuários.
